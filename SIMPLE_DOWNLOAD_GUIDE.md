# Simple Download Guide

## What is the File Explorer?
The File Explorer is the **left sidebar** in Cursor that shows all your files and folders. It looks like a folder icon 📁.

## How to Download - 3 Easy Ways:

### Method 1: Right-Click the Folder (EASIEST)
1. Look at the **left side** of your Cursor window
2. You should see a list of files and folders
3. Find the folder called **`haile-hotel-clone`**
4. **Right-click** on it
5. Look for options like:
   - "Download..."
   - "Export..."
   - "Save As..."
   - Or an icon that looks like a download arrow ⬇️
6. Click it and save to your computer

### Method 2: Use the Command Palette
1. Press **Ctrl+Shift+P** (or **Cmd+Shift+P** on Mac)
2. Type: `download`
3. Look for commands related to downloading files
4. Select the folder you want to download

### Method 3: Copy Files Manually
If the above don't work, I can help you copy all the files to a location you can access, or we can use terminal commands.
